Что такое Pygame?

Библиотека Python для создания игр и графических приложений

📖 Определение

Pygame — это набор модулей (частей) языка Python, которые позволяют создавать игры, рисовать фигуры, работать со звуком и обрабатывать нажатия клавиш.

Проще говоря: Pygame даёт вам инструменты, чтобы превратить текст программы в визуальное окно, где что-то происходит на экране.

🎯

Простота

Минимум кода для создания окна и отрисовки фигур. Идеально для начинающих.

📐

Логичность

Чёткая структура: инициализация → цикл → события → отрисовка → обновление.

🌍

Популярность

Используется в школах, университетах и на курсах по всему миру.

Возможности

2D-графика, звук, обработка клавиатуры и мыши, работа с изображениями.

️ Как это работает (общая схема)

  1. Вы пишете код на Python с использованием модуля pygame.
  2. Запускаете программу — открывается окно на экране.
  3. Программа работает в бесконечном цикле, пока вы не закроете окно.
  4. В цикле программа: слушает события → обновляет данные → рисует на экране.
Python — минимальная программа 
import pygame  # Подключаем библиотеку Pygame

pygame.init()  # Запускаем все системы Pygame

# Создаём окно размером 400x300 пикселей
screen = pygame.display.set_mode((400, 300))

# Бесконечный цикл — программа работает, пока окно открыто
running = True
while running:
    # Проверяем все события (нажатия клавиш, закрытие окна)
    for event in pygame.event.get():
        if event.type == pygame.QUIT:  # Если нажали крестик
            running = False  # Останавливаем цикл

    # Заполняем экран чёрным цветом
    screen.fill((0, 0, 0))

    # Показываем результат на экране
    pygame.display.flip()

pygame.quit()  # Завершаем работу Pygame

Инициализация и создание экрана

Два обязательных шага перед началом работы

⚙️ Шаг 1: pygame.init()

Эта команда запускает все внутренние системы Pygame: графику, звук, шрифты, ввод с клавиатуры.

Без этой строки остальные команды Pygame не будут работать. Её всегда пишут в самом начале программы.

Что происходит: Pygame готовит все инструменты к работе.

🖼️ Шаг 2: pygame.display.set_mode()

Эта команда создаёт окно на экране компьютера. Окно — это «холст», на котором вы будете рисовать.

В скобках указывается размер окна в пикселях: (ширина, высота).

  • (400, 300) — окно 400 пикселей в ширину и 300 в высоту
  • (800, 600) — окно побольше
Python — инициализация и экран 
import pygame  # Подключаем библиотеку

pygame.init()  # Запускаем все системы Pygame

# Создаём окно размером 600x400 пикселей
# set_mode возвращает объект "screen" — наш холст для рисования
screen = pygame.display.set_mode((600, 400))

# Меняем заголовок окна (необязательно, но удобно)
pygame.display.set_caption("Моя первая игра")

Игровой цикл (Game Loop)

Сердце любой игры — бесконечный цикл, который не даёт программе закрыться

🔄 Зачем нужен цикл?

Если написать программу без цикла, она выполнится один раз и сразу закроется. Окно появится и исчезнет за долю секунды.

Игровой цикл — это бесконечный цикл while running:, который постоянно повторяет три действия:

  1. Слушает события (нажатия клавиш, движение мыши, закрытие окна)
  2. Обновляет данные (двигает объекты, меняет счёт)
  3. Рисует на экране (показывает текущее состояние)

⏱️ clock.tick() — контроль скорости

Функция clock.tick(60) ограничивает цикл до 60 повторений в секунду (60 FPS).

Без этого цикл работал бы слишком быстро (тысячи раз в секунду), и игра была бы неуправляемой.

Что происходит: Программа делает паузу, чтобы цикл работал с нужной скоростью.

Python — структура игрового цикла 
import pygame

pygame.init()
screen = pygame.display.set_mode((600, 400))

# Создаём объект clock для контроля скорости
clock = pygame.time.Clock()

running = True
while running:  # БЕСКОНЕЧНЫЙ ЦИКЛ — основа игры
    
    # 1. ОБРАБОТКА СОБЫТИЙ
    for event in pygame.event.get():
        if event.type == pygame.QUIT:
            running = False

    # 2. ОБНОВЛЕНИЕ ДАННЫХ
    # (здесь меняются координаты объектов, счёт и т.д.)

    # 3. ОТРИСОВКА
    screen.fill((0, 0, 0))  # Очищаем экран чёрным цветом
    # (здесь рисуем фигуры, текст, изображения)

    # 4. ОБНОВЛЕНИЕ ЭКРАНА
    pygame.display.flip()  # Показываем результат

    # 5. КОНТРОЛЬ СКОРОСТИ
    clock.tick(60)  # Ограничиваем до 60 кадров в секунду

pygame.quit()
🔄

Визуализация: как работает цикл

⚠️ Важно: как остановить цикл?

Цикл while True: будет работать вечно. Чтобы программа могла завершиться, используют переменную-флаг:

  • running = True — цикл работает
  • running = False — цикл останавливается
  • Значение меняется, когда пользователь закрывает окно (событие QUIT)

События (Events)

Как программа узнаёт о действиях пользователя

👂 Что такое событие?

Событие — это сигнал о том, что что-то произошло: нажата клавиша, двигалась мышь, закрылось окно.

Pygame собирает все события в очередь. Программа должна проверять эту очередь и реагировать на нужные события.

❌

pygame.QUIT

Пользователь нажал крестик закрытия окна. Самое важное событие — без его обработки программу нельзя закрыть.

⌨️

pygame.KEYDOWN

Пользователь нажал клавишу на клавиатуре. Можно узнать, какую именно.

🖱️

pygame.MOUSEBUTTONDOWN

Пользователь нажал кнопку мыши. Можно узнать координаты клика.

🔄

pygame.event.get()

Функция, которая возвращает список всех событий, произошедших с последнего вызова.

Python — обработка событий 
import pygame

pygame.init()
screen = pygame.display.set_mode((600, 400))
running = True

while running:
    # Получаем список всех событий
    for event in pygame.event.get():

        # Проверяем: пользователь закрыл окно?
        if event.type == pygame.QUIT:
            running = False  # Останавливаем цикл

        # Проверяем: нажата ли клавиша?
        if event.type == pygame.KEYDOWN:
            if event.key == pygame.K_ESCAPE:
                running = False  # Esc тоже закрывает программу
            if event.key == pygame.K_SPACE:
                print("Нажат пробел!")  # Действие на пробел

    screen.fill((0, 0, 0))
    pygame.display.flip()

pygame.quit()
👂

Интерактив: имитация очереди событий

Добавляйте события в очередь, затем нажмите «Обработать», чтобы увидеть, как программа их читает.

📋 Структура обработки событий

  1. Вызываем pygame.event.get() — получаем список событий.
  2. Проходим по списку в цикле for event in ....
  3. Проверяем тип события: if event.type == pygame.QUIT.
  4. Выполняем нужное действие (например, running = False).

Непрерывное нажатие клавиш (get_pressed)

Плавное движение при удержании клавиши

🔑 Разница между event.get() и key.get_pressed()

pygame.event.get() — возвращает список событий. Реагирует на одно нажатие клавиши.

pygame.key.get_pressed() — возвращает состояние всех клавиш в данный момент: нажата или нет.

Когда использовать:

  • event.get() — для одиночных действий (прыжок, выстрел, пауза)
  • key.get_pressed() — для непрерывного движения (ходьба, бег)

Как работает get_pressed()

Функция возвращает список (массив) из True и False для каждой клавиши:

  • Если клавиша нажата — True
  • Если клавиша не нажата — False

Вы проверяете нужную клавишу по её коду: keys[pygame.K_RIGHT]

Python — непрерывное движение 
import pygame

pygame.init()
screen = pygame.display.set_mode((600, 400))
clock = pygame.time.Clock()

# Создаём игрока (квадрат)
player_x = 100
player_y = 200
player_speed = 5

running = True
while running:
    for event in pygame.event.get():
        if event.type == pygame.QUIT:
            running = False

    # Получаем состояние всех клавиш
    keys = pygame.key.get_pressed()

    # Проверяем каждую клавишу
    if keys[pygame.K_LEFT]:   # Стрелка влево
        player_x -= player_speed
    if keys[pygame.K_RIGHT]:  # Стрелка вправо
        player_x += player_speed
    if keys[pygame.K_UP]:     # Стрелка вверх
        player_y -= player_speed
    if keys[pygame.K_DOWN]:   # Стрелка вниз
        player_y += player_speed

    # Отрисовка
    screen.fill((0, 0, 0))
    pygame.draw.rect(screen, (0, 255, 0), (player_x, player_y, 50, 50))
    pygame.display.flip()

    clock.tick(60)

pygame.quit()
🎮

Интерактив: непрерывное движение

Нажмите и удерживайте кнопки направления, чтобы двигать квадрат. Отпустите — движение остановится (как key.get_pressed()).

⚠️ Важно

  • key.get_pressed() вызывается вне цикла обработки событий.
  • Движение происходит каждый кадр, пока клавиша нажата.
  • Скорость движения контролируется переменной (например, player_speed = 5).

Что такое класс Sprite?

Готовый шаблон (чертёж) для игровых объектов

📋 Проблема: много объектов

Когда в игре много объектов (игрок, враги, пули), нужно хранить для каждого:

  • Координаты X и Y
  • Картинку (изображение)
  • Скорость движения
  • Другие свойства

Если делать это вручную, код становится сложным и запутанным.

✅ Решение: класс Sprite

pygame.sprite.Sprite — это готовый шаблон (чертёж) для игровых объектов.

Вы создаёте свой класс на основе этого шаблона, и Pygame сам управляет координатами, картинкой и другими свойствами.

Аналогия: Sprite — это как анкета. У каждого объекта есть стандартные поля (имя, возраст, адрес), но значения разные.

Python — создание класса Sprite 
import pygame

# Создаём свой класс на основе готового шаблона Sprite
class Player(pygame.sprite.Sprite):
    # Наследуем все свойства и методы от pygame.sprite.Sprite
    
    def __init__(self):
        # Вызываем конструктор родительского класса
        super().__init__()
        
        # Здесь мы задаём внешность и позицию спрайта
        # (подробнее на следующем слайде)
        pass

# Создаём объект игрока
player = Player()

🔑 Ключевые моменты

  • class Player(pygame.sprite.Sprite): — создаём класс Player, который наследует от Sprite.
  • super().__init__() — обязательно вызываем в начале. Это запускает внутренний код Pygame.
  • После этого можно добавлять свои свойства и методы.
📐

Структура

Sprite даёт стандартную структуру для всех игровых объектов.

🔄

Удобство

Не нужно вручную хранить координаты и картинки для каждого объекта.

👥

Группы

Sprites можно объединять в группы и управлять ими одной командой.

Методы

Два обязательных атрибута: image и rect

Внешность и позиция спрайта

️ Правило: два обязательных свойства

У каждого спрайта ДОЛЖНЫ быть два свойства:

  1. self.image — то, как спрайт выглядит (поверхность Surface).
  2. self.rect — то, где он находится и какого он размера (прямоугольник).

Без этих двух свойств спрайт не будет работать.

🎨 self.image — внешность

self.image — это поверхность (Surface), на которой нарисован спрайт.

Можно создать простую поверхность и залить её цветом:

  • pygame.Surface((50, 50)) — создаёт поверхность 50x50 пикселей
  • image.fill((255, 0, 0)) — заливает красным цветом

Или загрузить картинку из файла:

  • pygame.image.load("player.png") — загружает изображение

📍 self.rect — позиция и размер

self.rect — это прямоугольник, который определяет:

  • Где находится спрайт (координаты x, y)
  • Какого он размера (ширина, высота)

Обычно создаётся автоматически из image:

  • self.rect = self.image.get_rect() — создаёт rect того же размера, что и image
  • self.rect.x = 100 — устанавливает позицию по X
  • self.rect.y = 200 — устанавливает позицию по Y
Python — создание простого спрайта (квадрата) 
import pygame

class Player(pygame.sprite.Sprite):
    def __init__(self):
        super().__init__()  # Обязательно!
        
        # Создаём поверхность (image) — квадрат 50x50 пикселей
        self.image = pygame.Surface((50, 50))
        self.image.fill((0, 255, 0))  # Заливаем зелёным цветом
        
        # Создаём прямоугольник (rect) того же размера
        self.rect = self.image.get_rect()
        
        # Устанавливаем начальную позицию
        self.rect.x = 100  # Позиция по X
        self.rect.y = 150  # Позиция по Y

# Создаём объект игрока
player = Player()
🎨

Визуализация: image и rect

Нажмите кнопки, чтобы увидеть разницу между image (внешность) и rect (рамка позиции).

Как это работает вместе

  1. self.image содержит картинку спрайта (например, зелёный квадрат).
  2. self.rect содержит координаты и размер (например, x=100, y=150, ширина=50, высота=50).
  3. Когда Pygame рисует спрайт, он берёт картинку из image и размещает её по координатам из rect.

Метод update() — поведение и движение

Как спрайт меняет своё состояние

🔄 Что такое update()?

update() — это специальный метод, который вызывается, когда нужно обновить состояние спрайта.

Например:

  • Подвинуть спрайт
  • Изменить направление
  • Проверить столкновения
  • Обновить анимацию

Когда вызывается: Обычно в игровом цикле, перед отрисовкой.

Как написать update()

Вы добавляете метод update() в свой класс Sprite:

  • Метод получает self — ссылку на сам спрайт
  • Внутри метода вы меняете свойства спрайта (обычно self.rect.x или self.rect.y)
Python — метод update() для движения вправо 
import pygame

class Player(pygame.sprite.Sprite):
    def __init__(self):
        super().__init__()
        self.image = pygame.Surface((50, 50))
        self.image.fill((0, 255, 0))
        self.rect = self.image.get_rect()
        self.rect.x = 50  # Начальная позиция
        self.rect.y = 100
    
    # Метод update() — вызывается для обновления состояния
    def update(self):
        # Двигаем спрайт вправо на 5 пикселей
        self.rect.x += 5
        
        # Если спрайт вышел за правый край экрана — возвращаем влево
        if self.rect.x > 600:
            self.rect.x = 50

# Создаём игрока
player = Player()

# В игровом цикле:
# player.update()  # Вызываем update() каждый кадр
🔄

Интерактив: метод update()

Нажмите «Вызвать update()», чтобы сдвинуть квадрат вправо на 30 пикселей (как в коде: self.rect.x += 30).

📋 Как использовать update() в игровом цикле

  1. Создаёте спрайт: player = Player()
  2. В игровом цикле вызываете: player.update()
  3. Метод update() меняет координаты спрайта
  4. Pygame рисует спрайт на новой позиции

Результат: Спрайт двигается по экрану.

Метод kill() — удаление спрайта

Как убрать объект из игры

🗑️ Что делает kill()?

Метод self.kill() автоматически удаляет спрайт из всех групп, в которых он состоит.

После вызова kill():

  • Спрайт больше не рисуется на экране
  • Спрайт не получает события
  • Спрайт не обновляется

Аналогия: Это как удалить файл из папки — он исчезает из списка.

Когда вызывать kill()?

Обычно kill() вызывается при выполнении какого-то условия:

  • Спрайт вышел за границы экрана
  • Спрайт столкнулся с другим объектом
  • Здоровье спрайта равно нулю
  • Игрок нажал кнопку удаления
Python — метод kill() с условием 
import pygame

class Bullet(pygame.sprite.Sprite):
    def __init__(self, x, y):
        super().__init__()
        self.image = pygame.Surface((10, 10))
        self.image.fill((255, 255, 0))  # Жёлтая пуля
        self.rect = self.image.get_rect()
        self.rect.x = x
        self.rect.y = y
    
    def update(self):
        # Двигаем пулю вверх
        self.rect.y -= 10
        
        # Если пуля вышла за верхний край экрана — удаляем её
        if self.rect.y < 0:
            self.kill()  # Удаляем спрайт из всех групп

# Создаём пулю
bullet = Bullet(300, 400)

# В игровом цикле:
# bullet.update()  # Пуля двигается и автоматически удаляется при выходе за экран
🗑️

Интерактив: метод kill()

Нажмите «Показать спрайт», затем «Вызвать kill()», чтобы увидеть, как спрайт исчезает.

⚠️ Важно: что происходит после kill()?

  • Спрайт удаляется из групп, но объект всё ещё существует в памяти Python.
  • Если вы сохраните ссылку на спрайт (bullet = Bullet(...)), вы всё ещё можете обращаться к его свойствам.
  • Но Pygame больше не будет его рисовать или обновлять.

Рекомендация: После kill() не используйте спрайт — создайте новый, если нужен.

Группы спрайтов и функции отслеживания

Управление множеством объектов и проверка столкновений

pygame.sprite.Group() — контейнер для спрайтов

Группа — это объект, который хранит множество спрайтов и позволяет управлять ими одной командой.

Методы группы:

  • group.add(sprite1, sprite2, ...) — добавить спрайты в группу
  • group.remove(sprite) — удалить спрайт из группы
  • group.update() — вызвать update() для всех спрайтов
  • group.draw(screen) — нарисовать все спрайты на экране

💥 Функции проверки столкновений

Pygame предоставляет готовые функции для проверки пересечения спрайтов:

1. spritecollide(sprite, group, dokill)

  • Проверяет столкновение одного спрайта со всеми спрайтами в группе
  • Возвращает список столкнувшихся спрайтов
  • Параметр dokill=True — автоматически удаляет столкнувшиеся спрайты из группы

2. groupcollide(group1, group2, dokill1, dokill2)

  • Проверяет столкновения между всеми спрайтами первой группы и всеми спрайтами второй группы
  • Возвращает словарь: ключ — спрайт из group1, значение — список столкнувшихся спрайтов из group2
  • Параметры dokill1 и dokill2 — удалять ли спрайты из соответствующих групп
Python — группы и столкновения 
import pygame

class Enemy(pygame.sprite.Sprite):
    def __init__(self, x, y):
        super().__init__()
        self.image = pygame.Surface((40, 40))
        self.image.fill((255, 0, 0))  # Красный враг
        self.rect = self.image.get_rect()
        self.rect.x = x
        self.rect.y = y

# Создаём группу врагов
enemies = pygame.sprite.Group()

# Добавляем врагов
enemy1 = Enemy(100, 50)
enemy2 = Enemy(200, 50)
enemy3 = Enemy(300, 50)
enemies.add(enemy1, enemy2, enemy3)

# Создаём игрока
player = Player()

# В игровом цикле:
# Проверяем столкновение игрока со всеми врагами
hit_enemies = pygame.sprite.spritecollide(player, enemies, False)

if hit_enemies:
    print("Столкновение! Количество врагов:", len(hit_enemies))

# Или удаляем столкнувшихся врагов:
# hit_enemies = pygame.sprite.spritecollide(player, enemies, True)

Интерактив: проверка столкновений

📋 Когда использовать какую функцию?

  • spritecollide — когда нужно проверить одного персонажа (игрока) против группы объектов (врагов, пуль)
  • groupcollide — когда нужно проверить столкновения между двумя группами (например, пули игрока против врагов)

Базовые столкновения (Collision Detection)

Проверка пересечения двух конкретных спрайтов

collide_rect() — проверка двух спрайтов

Функция pygame.sprite.collide_rect(sprite1, sprite2) проверяет, пересекаются ли два конкретных спрайта.

Возвращает:

  • True — если спрайты пересекаются
  • False — если не пересекаются

Как работает: Сравнивает прямоугольники (rect) двух спрайтов. Если они пересекаются — столкновение есть.

Python — проверка столкновения двух спрайтов 
import pygame

# Создаём два спрайта
player = Player()
enemy = Enemy(200, 100)

# В игровом цикле:
# Проверяем столкновение
if pygame.sprite.collide_rect(player, enemy):
    # Столкновение произошло!
    print("Игрок столкнулся с врагом!")
    # Можно уменьшить здоровье, убрать жизнь и т.д.
    player.health -= 10
📐

Интерактив: collide_rect()

Двигайте синего игрока вправо к красному врагу. Нажмите «Проверить столкновение», чтобы узнать, пересекаются ли они.

Как определить столкновение?

Два прямоугольника пересекаются, если:

  • Правый край первого > левого края второго
  • Левый край первого < правого края второго
  • Нижний край первого > верхнего края второго
  • Верхний край первого < нижнего края второго

Pygame делает эту проверку автоматически через collide_rect().

blit() и flip(): Двойная буферизация

Разница между рисованием в памяти и показом на экране

🖼️ Двойная буферизация

Pygame использует два «холста» (буфера):

  1. Видимый буфер — то, что сейчас показано на экране.
  2. Невидимый буфер — то, на котором вы рисуете.

Когда вы вызываете pygame.draw.rect(), фигура рисуется на невидимом буфере. Пользователь её ещё не видит.

Чтобы показать результат, нужно вызвать pygame.display.flip() — эта команда меняет буферы местами, и нарисованное становится видимым.

Аналогия: художник и витрина

Представьте художника, который рисует картину за занавеской (невидимый буфер).

Зрители видят только готовую картину в витрине (видимый буфер).

Когда художник заканчивает, он говорит: flip() — и занавеска открывается, показывая новую картину.

Зачем это нужно: Чтобы зрители не видели процесс рисования, только готовый результат.

🖼️

Визуализация: два буфера

📺 Видимый экран
🎨 Невидимый буфер (рисуем здесь)
1. Нажмите «Нарисовать фигуру» — она появится в невидимом буфере.
2. Нажмите «display.flip()» — буферы поменяются, и фигура станет видимой.
Python — полный пример с обновлением экрана 
import pygame

pygame.init()
screen = pygame.display.set_mode((600, 400))

RED = (255, 0, 0)
BLUE = (0, 100, 255)
WHITE = (255, 255, 255)

running = True
while running:
    for event in pygame.event.get():
        if event.type == pygame.QUIT:
            running = False

    # ШАГ 1: Очищаем невидимый буфер белым цветом
    screen.fill(WHITE)

    # ШАГ 2: Рисуем фигуры на невидимом буфере
    # (пользователь пока ничего не видит!)
    pygame.draw.rect(screen, RED, (100, 100, 200, 150))
    pygame.draw.circle(screen, BLUE, (450, 200), 70)

    # ШАГ 3: Показываем результат на экране
    # Теперь пользователь видит нарисованное
    pygame.display.flip()

pygame.quit()

Шрифты и текст (Fonts and Text)

Как отображать текст на экране

3 шага отображения текста

Чтобы показать текст в Pygame, нужно выполнить три действия:

  1. Создать объект шрифта — выбрать размер и стиль
  2. Отрисовать текст на поверхности — превратить текст в картинку
  3. Показать поверхность на экране — использовать blit()
Python — отображение текста 
import pygame

pygame.init()
screen = pygame.display.set_mode((600, 400))

# ШАГ 1: Создаём объект шрифта
# font.SysFont(название_шрифта, размер, жирный=False, курсив=False)
font = pygame.font.SysFont("Arial", 36, bold=True)

# ШАГ 2: Отрисовываем текст на поверхности
# font.render(текст, сглаживание, цвет)
text_surface = font.render("Привет, Pygame!", True, (255, 255, 255))

# ШАГ 3: Показываем на экране
# screen.blit(поверхность, (x, y))
screen.blit(text_surface, (150, 200))

pygame.display.flip()

Параметры функций

pygame.font.SysFont():

  • Первый параметр — название шрифта ("Arial", "Courier", "Times")
  • Второй параметр — размер в пикселях
  • bold=True — жирный шрифт
  • italic=True — курсив

font.render():

  • Первый параметр — текст (строка)
  • Второй параметр — сглаживание (True для чёткого текста)
  • Третий параметр — цвет (R, G, B)

Музыка и звуки (Sound and Music)

Разница между фоновой музыкой и звуковыми эффектами

🎵 Два типа аудио в Pygame

Pygame предоставляет два разных инструмента для работы со звуком:

1. pygame.mixer.music — для фоновой музыки

  • Играет один файл в фоновом режиме
  • Подходит для длинных музыкальных треков
  • Можно ставить на паузу, возобновлять, менять громкость

2. pygame.mixer.Sound — для звуковых эффектов

  • Можно создать много объектов Sound
  • Подходит для коротких звуков (выстрел, прыжок, столкновение)
  • Можно играть несколько звуков одновременно
Python — музыка и звуки 
import pygame

pygame.init()
screen = pygame.display.set_mode((600, 400))

# Инициализируем модуль звука
pygame.mixer.init()

# ФОНОВАЯ МУЗЫКА
# Загружаем и запускаем музыку
pygame.mixer.music.load("background.mp3")
pygame.mixer.music.play(-1)  # -1 = бесконечный повтор
pygame.mixer.music.set_volume(0.5)  # Громкость от 0.0 до 1.0

# ЗВУКОВЫЕ ЭФФЕКТЫ
# Создаём объекты Sound
jump_sound = pygame.mixer.Sound("jump.wav")
shoot_sound = pygame.mixer.Sound("shoot.wav")
hit_sound = pygame.mixer.Sound("hit.wav")

running = True
while running:
    for event in pygame.event.get():
        if event.type == pygame.QUIT:
            running = False
        
        # Воспроизводим звук при нажатии клавиши
        if event.type == pygame.KEYDOWN:
            if event.key == pygame.K_SPACE:
                jump_sound.play()  # Играем звук прыжка
            if event.key == pygame.K_f:
                shoot_sound.play()  # Играем звук выстрела

    screen.fill((0, 0, 0))
    pygame.display.flip()

pygame.quit()

📋 Методы для работы со звуком

Для музыки (mixer.music):

  • pygame.mixer.music.load(filename) — загрузить файл
  • pygame.mixer.music.play(loops) — играть (loops=-1 для бесконечного повтора)
  • pygame.mixer.music.stop() — остановить
  • pygame.mixer.music.pause() — пауза
  • pygame.mixer.music.unpause() — возобновить
  • pygame.mixer.music.set_volume(value) — громкость (0.0 до 1.0)

Для звуков (Sound):

  • sound = pygame.mixer.Sound(filename) — создать объект
  • sound.play() — воспроизвести
  • sound.stop() — остановить
  • sound.set_volume(value) — громкость

️ Важные моменты

  • Вызывайте pygame.mixer.init() после pygame.init()
  • Музыка поддерживает MP3, OGG, WAV
  • Sound поддерживает только WAV и OGG
  • Звуковые файлы должны быть в той же папке, что и программа

Полный пример: Мини-игра

Объединение всех концепций в одной программе

🎮 Что будет в игре

Создадим простую игру, где:

  • Игрок (зелёный квадрат) управляется стрелками
  • Враги (красные квадраты) падают сверху
  • Счёт увеличивается, пока игрок жив
  • При столкновении с врагом — игра заканчивается
Python — мини-игра 
import pygame
import random

pygame.init()
screen = pygame.display.set_mode((600, 400))
clock = pygame.time.Clock()
font = pygame.font.SysFont("Arial", 24)

# Класс игрока
class Player(pygame.sprite.Sprite):
    def __init__(self):
        super().__init__()
        self.image = pygame.Surface((40, 40))
        self.image.fill((0, 255, 0))
        self.rect = self.image.get_rect()
        self.rect.x = 280
        self.rect.y = 350
        self.speed = 5
    
    def update(self):
        keys = pygame.key.get_pressed()
        if keys[pygame.K_LEFT] and self.rect.x > 0:
            self.rect.x -= self.speed
        if keys[pygame.K_RIGHT] and self.rect.x < 560:
            self.rect.x += self.speed

# Класс врага
class Enemy(pygame.sprite.Sprite):
    def __init__(self):
        super().__init__()
        self.image = pygame.Surface((30, 30))
        self.image.fill((255, 0, 0))
        self.rect = self.image.get_rect()
        self.rect.x = random.randint(0, 570)
        self.rect.y = -30
    
    def update(self):
        self.rect.y += 3
        if self.rect.y > 400:
            self.kill()

# Создаём игрока и группу врагов
player = Player()
enemies = pygame.sprite.Group()

score = 0
enemy_timer = 0
running = True
game_over = False

while running:
    for event in pygame.event.get():
        if event.type == pygame.QUIT:
            running = False
        if event.type == pygame.KEYDOWN and event.key == pygame.K_r and game_over:
            # Перезапуск игры
            player = Player()
            enemies = pygame.sprite.Group()
            score = 0
            game_over = False

    if not game_over:
        # Обновление
        player.update()
        
        enemy_timer += 1
        if enemy_timer >= 60:  # Новый враг каждую секунду
            enemies.add(Enemy())
            enemy_timer = 0
        
        enemies.update()
        
        # Проверка столкновений
        if pygame.sprite.spritecollide(player, enemies, False):
            game_over = True
        
        score += 1

    # Отрисовка
    screen.fill((30, 30, 30))
    
    if not game_over:
        screen.blit(player.image, player.rect)
        enemies.draw(screen)
        
        # Показываем счёт
        score_text = font.render(f"Счёт: {score}", True, (255, 255, 255))
        screen.blit(score_text, (10, 10))
    else:
        # Экран Game Over
        game_over_text = font.render("GAME OVER — Нажмите R для перезапуска", True, (255, 0, 0))
        screen.blit(game_over_text, (50, 200))

    pygame.display.flip()
    clock.tick(60)

pygame.quit()

Ключевые моменты кода

  1. Классы Sprite — Player и Enemy наследуют от pygame.sprite.Sprite
  2. Метод update() — двигает игрока и врагов
  3. Группа спрайтов — enemies хранит всех врагов
  4. spritecollide() — проверяет столкновение игрока с врагами
  5. get_pressed() — плавное управление игроком
  6. Текст — показывает счёт на экране

  • Добавить бонусы (аптечки, усиления)
  • Сохранять рекорд в файл
  • Добавить уровни сложности
